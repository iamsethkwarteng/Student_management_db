#Student Management System Database

A PostgreSQL database for managing students, courses, insrtuctors, and enrollments.

##Database Tables

| Table | Description |
| -----|-----------|
|departments| Academic departments|
|students| student records|
|instructors| teaching staff|
|courses | available courses |
|classes| course selections per semester |
| enrollments | student-class registration |

## how to run
1. create database: `create databse student_management;`
2. Run schema files in order (01,02,03,...)
3. Run seed_data.sql for sample data
